# 模型结构与验证边界

仓库只实现直接使用官方预训练 DINOv2 的监督检测器。命令和数据说明统一见
[TRAINING.md](TRAINING.md)。

## 数据流

```text
原图 + YOLO 标签
  ↓ 同步几何增广 / 缩放到方形检测输入（默认 1280）
RGB [0,1]
  ↓ 缩放到 DINO 输入（默认 448）；ImageNet mean/std 归一化
官方预训练 DINOv2 ViT-B/14（默认冻结）
  ↓ 4 个分布式中间层：ViT-B 为 2/5/8/11（0-based）
四个可训练 1×1 投影 + 空间插值
  ↓ stride 4/8/16/32 接口
PAN 特征融合（stride 8/16/32）
  ↓ P3、P5 双尺度检测头
共享类别 / 距离预测 + 两种 objectness 训练监督
  ↓ 推理使用一对一 objectness × 最大类别概率
top-k / 得分过滤 / 可选同类别 NMS
  ↓ 转换回原图坐标
已知缺陷类别、框和分数
```

这些金字塔层来自同一 ViT patch 网格的不同深度，不是原生多分辨率特征。
插值不能恢复缩小时丢失的细节。DINO 输入必须是 14 的倍数，448 对应 32×32 patch 网格；
小缺陷可对比 672，但 attention 显存和计算会增加。检测输入当前要求方形且为 32 的倍数。

## 可训练参数

- `dino_freeze: true`：encoder 不反传、始终 eval；四个适配器、PAN 和检测头正常训练。
  使用 `no_grad` 而不是 `inference_mode`，确保适配器反向传播可以保存输入。
- `dino_freeze: false`：encoder 也参与训练，optimizer 单独分组使用更小学习率。
- 新头仍是随机初始化，不存在官方的本数据集 19 类检测头权重。
- 默认 Softplus 确保负距离 logit 也有梯度。
- dense box loss 按 `(batch, cell, l/t/r/b)` 选择数据，与网格点逐点对应。
- 训练期的 box-derived alignment 只是检测头辅助监督，不是独立的前景／异常检测分支。

## 权重与结果

首次构造请求官方 hub `pretrained=True`；本地官方 `.pth` 严格加载。
检测 checkpoint 保存整个 ViT、适配器、PAN 和检测头。恢复时仅构造架构，再严格加载所有张量。
缺失键或尺寸不匹配不会被默默忽略，CNN／蒸馏 checkpoint 不受支持。

推理只输出模型配置中的已知类别，不生成未知异常、不提供异常图兜底，也不保证大缺陷不漏。
`large_recall` 仅衡量大框的定位覆盖，不要求类别一致，应结合正式的分类检测 P/R 一起看。
没有正常验证图片时 FPR 是未测量，而不是零。

## 不应推导的结论

- DINOv2 预训练特征不等于检测头预训练，不保证快速达到某个精确率。
- 同类 NMS 是后处理，不证明主干学得更快。它也会影响延迟，不能宣称 NMS-free。
- ViT-B encoder 约 86.6M 参数，包含在推理与 checkpoint 中，不适用原轻量模型的 FPS 预算。
- 单元测试、合成输入和随机权重架构检查只能验证实现接口，不能替代真实标注数据实验。
- 六张量 PyTorch 导出接口经过等价性测试；真实 ViT 的 ONNX/TensorRT 部署尚未验证。

正式评估应固定原始图划分，分别控制主干、冻结策略、NMS 和阈值；最终效果需在独立测试集确认。
